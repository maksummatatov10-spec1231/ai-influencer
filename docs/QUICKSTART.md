# Быстрый старт — 10 минут чтобы понять

1. Открой студию http://localhost:8000 (или preview ссылку)
2. В блоке "Генератор промптов" введи сцену → нажми Сгенерировать → Копировать
3. Вставь промпт в Leonardo AI / syntx.ai / APOB с референсом assets/amina_reference.jpg
4. Сгенерируй 20 фото → выбери лучшие
5. Загрузи лучшее фото в Kling → Image to Video → получи 5-сек клип
6. Текст подписи → блок "Генератор подписей" → выбери Кавказ/Город/Образы
7. План на месяц → прокрути вниз → копируй промпт+подпись для каждого дня

Готово — у тебя контент на 30 дней.
